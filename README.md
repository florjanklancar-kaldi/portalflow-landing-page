# PortalFlow Landing Page

Create a simple, clean landing page for a fictional SaaS product called PortalFlow.

Requirements:

Use React + TypeScript with the project's default Lovable stack.

Create only a single landing page.

Include:

Header with logo text "PortalFlow"

Navigation links: Product, Features, Pricing

Primary CTA button: "Get started"

Hero section with headline: "A simpler way to manage your work"

Short supporting paragraph

One primary CTA button

Simple 3-column features section

Minimal footer

Make it responsive for desktop and mobile.

Use a professional, modern SaaS design.

Do not add authentication, database, backend functionality, or external integrations.

Do not install unnecessary dependencies.

Keep the implementation simple and easy to modify later.

After creating the page, do not make any additional changes.

This project was built with [Lovable](https://lovable.dev).
